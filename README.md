## Setup

To run this project, simply build and run main.cpp to access the main menu

## Instructions

To add information to the database, enter "1" while at the main menu, and enter the file name of a valid input file (large.txt, small.txt, valid_file.txt)
After loading posts into the database, select any of the other options to view the different posts on the social media network.

(Main Menu Instructions)
"Welcome to CPPeers"
"The options are: "
"1. load data file and add information"
"2. show posts by user"
"3. show posts with hashtag"
"4. show most popular hashtag"
"9. quit"
"--------> Enter your option: "

## Info

This project is a simple social media network, and has capabilites that allow it to store multiple posts from an input file, find the most popular hashtag in its database, and filter posts by user or hashtag.
